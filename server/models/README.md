# Modelos

Aquí se definirán las estructuras y validaciones de los datos del CRM.
El acceso a Firestore corresponde a los servicios de `server/services`, usando
la instancia `db` exportada por `server/config/firebase.js`.

Todavía no existen modelos de clientes ni registros simulados. La configuración
de Firebase está preparada; cada compañero debe configurar sus variables de
entorno para acceder a una base real.

Consultar la [referencia técnica](../documents/README.md) y la
[guía de replicación](../documents/GUIA_REPLICACION.md).
